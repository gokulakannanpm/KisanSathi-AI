===============================================================================
 KISANSATHI-AI EXTERNAL API & PROVIDER CONFIGURATION DOCUMENTATION
===============================================================================

This document lists the optional external environment variables and API keys
that can be configured for live weather, mandi prices, and AI LLM models.

Do NOT put actual secret key values in source code or version control.

-------------------------------------------------------------------------------
 1. DATABASE CONFIGURATION
-------------------------------------------------------------------------------
Variable Name : DATABASE_URL
Purpose       : Specifies the database connection string for farmer profiles,
                diary entries, and persistent action acknowledgements.
Required for  : All operations (default SQLite database)
Consumed by   : app/models.py
Default       : sqlite:///./kisansathi.db
Configure in  : .env

-------------------------------------------------------------------------------
 2. WEATHER PROVIDER CONFIGURATION
-------------------------------------------------------------------------------
Variable Name : WEATHER_API_PROVIDER
Purpose       : Switches between deterministic demo weather and live OpenWeatherMap API.
Required for  : Live weather forecasts
Consumed by   : app/services/weather_service.py
Default       : mock (Deterministic Doppler Radar Dataset)
Configure in  : .env

Variable Name : OPENWEATHER_API_KEY
Purpose       : API key for OpenWeatherMap live weather forecast API
Required for  : Live OpenWeatherMap integration (when WEATHER_API_PROVIDER=openweathermap)
Consumed by   : app/services/weather_service.py
Configure in  : .env
Developer Doc : https://openweathermap.org/api

-------------------------------------------------------------------------------
 3. MANDI MARKET PRICES CONFIGURATION
-------------------------------------------------------------------------------
Variable Name : MANDI_API_PROVIDER
Purpose       : Switches between deterministic AGMARKNET market prices and live API.
Required for  : Live APMC mandi price feeds
Consumed by   : app/services/mandi_service.py
Default       : mock (AGMARKNET Live API Baseline Cache)
Configure in  : .env

Variable Name : MANDI_API_KEY
Purpose       : API key for Data.gov.in / AGMARKNET live market API
Required for  : Live AGMARKNET market prices (when MANDI_API_PROVIDER=agmarknet)
Consumed by   : app/services/mandi_service.py
Configure in  : .env
Developer Doc : https://data.gov.in

-------------------------------------------------------------------------------
 4. AI GROQ INTELLIGENCE CONFIGURATION
-------------------------------------------------------------------------------
Variable Name : GROQ_API_KEY
Purpose       : API key for Groq Cloud ultra-fast inference (Llama 3.3 70B / 8B)
Required for  : Live Groq AI contextual explanation mode
Consumed by   : app/routers/ai.py
Configure in  : .env
Developer Doc : https://console.groq.com/keys

Variable Name : GROQ_MODEL
Purpose       : Supported Groq model identifier (e.g. llama-3.3-70b-versatile)
Required for  : Model selection
Consumed by   : app/routers/ai.py
Default       : llama-3.3-70b-versatile
Configure in  : .env

Fallback Mode : When GROQ_API_KEY is not provided, the platform automatically
                operates in deterministic offline rule engine fallback mode.
